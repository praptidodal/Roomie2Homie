🏠 Roomie2Hoomie



Find a roommate who feels like home.



Roomie2Hoomie is an MCA group project designed to help students and young professionals find compatible roommates and suitable accommodation. It brings lifestyle preferences, roommate discovery, room listings, and communication together in one place.



🚧 Project status: In development. The user journey and features below describe what the completed website is intended to offer. Individual features will be available as they are built.



✨ What the website will offer



Roommate recommendations: Discover people whose habits, budget, and preferred location suit yours.



Compatibility insights: See a match score and an explanation of shared preferences.



Room listings: Browse available rooms and flats by location and budget.



Connections and chat: Send a match request and talk after both people agree to connect.



Trust features: View verification status and report concerns.



🧭 How to use Roomie2Hoomie



Once these features are available, the intended experience is:



Create an account and sign in.



Complete your profile with your location, budget, move-in plans, and a short introduction.



Answer the lifestyle quiz about habits such as cleanliness, sleep schedule, food, and guests.



Explore roommate recommendations. Use filters and read Why You Matched to understand each suggestion.



Send a match request to someone you would like to get to know. If they accept, start a conversation.



Browse room listings to compare rent, location, availability, and amenities. Users with an available room can create a listing.



Protect your personal information and meet potential roommates safely before making housing decisions.

💻 Run locally



Clone the repository:



git clone https://github.com/praptidodal/Roomie2Hoomie.git

cd Roomie2Hoomie



After the frontend and backend starters have been added, open two terminals:



\# Terminal 1: frontend

cd frontend

npm install

npm run dev



\# Terminal 2: backend

cd backend

npm install

npm start



Open the local URL displayed by Vite. The backend starter's health endpoint is planned at http://localhost:5000/api/health. When database integration is added, copy backend/.env.example to backend/.env and enter your own local settings; never commit .env.
